# GC 含量

GC 含量是指 DNA 或 RNA 序列中鸟嘌呤（G）和胞嘧啶（C）所占的比例，计算方式为 (G + C) / 序列总长度。G 与 C 之间有三个氢键，A 与 T 之间只有两个，所以 GC 含量越高，双链越稳定，解链温度（Tm）越高。

应用：设计 PCR 引物时，GC 含量一般控制在 40%–60%；测序中 GC 偏好（GC bias）会导致高 GC 或低 GC 区域覆盖度偏低；不同物种基因组的 GC 含量差异很大，可以作为物种特征。CpG 岛是 GC 含量高、CpG 二核苷酸富集的区域，常位于启动子附近，与 DNA 甲基化调控相关。

本系统的序列分析工具可以直接计算一段序列的 GC 含量。
